# Open Graph image

`repo-graveyard-1200x630.jpg` is the share image used for Open Graph and Twitter cards. It is a static, hand-exported file. It is not generated by a script or a runtime route.

Current file: 1200x630 JPEG, about 137 KB (budget: under 300 KB).

## How it was produced (and how to regenerate it)

1. Open `public/art/place-gate.webp` in an image editor (Photoshop, Affinity, GIMP, Figma, Photopea).
2. Set the canvas to 1200x630 px.
3. Cover-fit the artwork and centre it, so the canvas is fully covered. Crop the overflow and do not letterbox.
4. Optionally add the "Repo Graveyard" wordmark. Keep it inside the safe area, away from the edges, because some platforms crop.
5. Export as JPEG at quality 80-85. Check that the file is under 300 KB.
6. Save it as `public/og/repo-graveyard-1200x630.jpg`, replacing the existing file.

## The `OG_IMAGE_READY` flag

`lib/site-meta.ts` exports `OG_IMAGE_READY`.

- `true`: metadata points at `/og/repo-graveyard-1200x630.jpg` (1200x630).
- `false`: metadata falls back to `/art/place-gate.webp`.

The JPEG is committed, so the flag is already `true`. If you ever remove the JPEG, set it back to `false` until a new export is in place. When you add a first export, set it to `true`.

Regenerating the file at the same path and size needs no code change.
